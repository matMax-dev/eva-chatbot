¿Por qué en OnVisible?

Este código se ejecuta automáticamente en cuanto el usuario abre la pantalla en Power Apps. Esto asegura que la colección del chat (colMensajes) y las variables de control estén creadas y listas antes de pintar los elementos visuales.

Paso 2 de 3

Fórmula de inicialización (Power Fx)

Power Fx

Copia la siguiente fórmula e insértala en la barra de fórmulas de la propiedad OnVisible:

Screen.OnVisible 
UpdateContext({ varEVACargando: false });

ClearCollect(
    colMensajes,
    {
        ID: 1,
        Remitente: "EVA",
        Texto: "¡Hola! Soy EVA, tu asistente virtual. ¿En qué te puedo ayudar hoy?",
        Fecha: Now(),
        EsBot: true
    }
);
toggle_on UpdateContext(...)

Crea una variable local llamada varEVACargando y la pone en falso. Servirá para mostrar la animación de "EVA está escribiendo...".

playlist_add_check ClearCollect(...)

Limpia la colección de chat y añade el primer registro: el mensaje de bienvenida con remitente "EVA", la hora actual y la marca EsBot: true.
